# HeatWatch Chennai

An urban heat monitoring dashboard showing hotspot locations, temperature trends, recommended interventions, and estimated budgets.

## View the dashboard

Open [src/index.html](src/index.html) in a browser, or start a local server from the project folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/src/index.html`.

The project also includes the Java source in [src/Main.java](src/Main.java).
